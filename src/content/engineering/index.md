本组是实现侧的单一事实来源。**RD** 维护架构 / 契约 / 领域 / 规范 / 协作；**FE** 维护前端结构。改栈、改写回或推送约定、改模块边界：**先改文档再改代码**。本工程无自建后端。

## 本组文档

| 文档 | 写什么 | 维护 |
| --- | --- | --- |
| [技术架构](/engineering/architecture) | 栈、模块、数据流、质量属性 | RD |
| [接口契约](/engineering/contracts) | 浏览器写回、Git 平台、角色约定（无自建后端） | RD |
| [领域设计](/engineering/domain) | 概念、边界、不变量 | RD |
| [工程规范](/engineering/conventions) | 目录、命名、提交、禁止事项 | RD |
| [研发协作](/engineering/collab) | 分支、评审、联调约定 | RD |
| [前端结构](/engineering/frontend) | 路由、状态、组件契约、无障碍 | FE |

产品要「做什么」以 [产品需求](/product/prd) 为准；本组只回答「怎么做、约束是什么」。
