## 限界上下文

| 上下文 | 职责 | 核心对象 | 对接角色 |
| --- | --- | --- | --- |
| 工作空间 | 文档导航、渲染、角色写权限、本地写回 | 文档、角色、工作目录 | FE / POM |
|  |  |  |  |

## 核心对象

| 对象 | 含义 | 关键属性 | 生命周期 |
| --- | --- | --- | --- |
| 文档 Doc | `src/content` 里一篇 Markdown | slug、title、正文、relPath | 创建 → 编辑 → 归档 |
| 角色 Role | 配置中心中的七个身份 | id、可写 slug | 本机勾选，不入库 |
| 工作目录 | 用户授权的项目根 | FileSystemDirectoryHandle | 授权 → 写回 → 取消 |
| 附件图 | 文档目录下 `assets/` | 相对路径 | 粘贴 → 写盘 → 随仓库提交 |
| 代码空间 | 远程 Git 绑定 | 平台、仓库、分支 | 绑定 → 提交推送 → 取消 |

## 状态机

**文档**

```text
只读引用 →（角色有权且已授权目录）→ 可编辑 → 保存写回 → 只读展示
```

**发布（若有服务端，替换下面）**

```text
开发 → 测试 → 预发 → 生产
失败则按运维页回滚
```

## 业务规则

1. 未勾选角色不能保存。
2. 勾选角色后只能改自己负责的 slug。
3. 未授权本地目录时，页面可改预览，但不能写回文件。
4. （当前项目规则）
