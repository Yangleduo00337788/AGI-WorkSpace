PM 维护。一页说清「给谁、解决什么、做哪些、不做什么」。

## 定位

- 一句话定位：给团队和 AI Agent 用的**项目工作空间模版**，用 Markdown 沉淀上下文，Vue 只做壳子。
- 和竞品 / 旧系统的差异：不做 CMS、不做每篇一个 Vue 页；知识在 `src/content/`，可被 Agent 直接读。

## 愿景

（12 个月后）新成员或 Agent 打开工作空间，能在一次阅读内掌握范围、角色、接口和发布方式，不必翻聊天记录。

## 功能清单（当前版本）

| 模块 | 能力 | 优先级 | 状态 |
| --- | --- | --- | --- |
| 文档壳 | MD 导航 / 搜索 / 主题 / 中英 | P0 | 已完成 |
| 角色 | 七角色勾选与写权限 | P0 | 已完成 |
| 本地写回 | 授权目录后保存即改 MD | P0 | 已完成 |
| 预览编辑 | 不写 MD 语法也能改文档 | P0 | 已完成 |
| 后端 / 账号 | 多用户云端协同 | P2 | 明确延后 |

## 产品边界

- **本版本包含：** 七角色模板文档、本地目录授权写回、预览编辑、静态部署。
- **明确延后：** 登录账号、评论、实时协作、服务端 CMS。
- **由其它系统负责：** 代码仓库、CI、设计工具本身。

## 成功标准

- [ ] 七个角色都能在系统配置里勾选，并只改自己的文档
- [ ] 保存后磁盘上的 `src/content/*.md` 已更新
- [ ] 新成员按首页「先读这些」能找到概述、目标、架构
