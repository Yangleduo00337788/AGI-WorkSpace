POM 可维护本页。按下面顺序使用本工作空间。

## 第一次打开

1. 用 **Chrome 或 Edge** 打开预览（`npm run dev`）
2. 到 [配置中心](/settings) 勾选你的角色（可多选）
3. 授权本机项目根目录（里面要有 `src/content`）
4. 需要远程同步时再绑定代码空间（GitHub / Gitee / GitLab）

未勾选角色时所有文档只读。未授权目录时可以读打包进来的文档，但不能保存到磁盘。

## 怎么读

- **左侧：** 文档分类树（开始阅读、项目、产品、设计、研发、质量、交付、记录）
- **首页：** 同一棵树，标题是「开始阅读」，可逐级展开
- **本页右侧：** 当前文档小标题
- 顶部搜索：`Ctrl` / `Cmd` + `K`

建议阅读顺序：

1. [项目介绍文档](/start/project-intro)
2. [AGI-WorkSpace 新范式](/start/paradigm)
3. 本页
4. 再进入你角色对应的分类

## 怎么改

- 有权限的文档会出现「编辑」。在预览里改文字和表格，不必手写 Markdown。
- 可粘贴或插入图片，文件落到该文档目录的 `assets/`。
- 「新建文档」写到当前角色能维护的目录；文件名只用英文、数字、连字符。勾选「作为目录」会生成 `index.md`。
- 根目录 [项目首页](/) 不能删。
- `src/content/space/` 下的文档：只要勾选了任意角色就可以改。

## 怎么交给仓库

绑定代码空间后，在配置中心提交推送。会按 `.gitignore` 提交整个仓库。现阶段**没有**应用内 pull / 冲突合并。

## 给 Agent

改代码或文档前让 Agent 先读根目录 `AGENT.md`。保存 Harness 里的 AGENT.md 时，应用会同步仓库根目录那一份。
